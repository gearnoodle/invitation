# CLAUDE.md — Invitation blog

Blog posts for the INVITATION project, one Markdown file per post.

## Conventions

- **File names:** `invNNN-slug.md`, for example `inv006-no-blame-for-someone-who-hurts-people.md`. The slug is the post title in lowercase, with words joined by hyphens and punctuation dropped.
- **Title line:** `# INVNNN: Title`.
- **Never link to other posts.** Links are a hassle to keep right. Refer to another post by its code only, for example "INV003", with no link.
